### 核心思路：防跌落 = 黑胶带禁区（同构检测）

TCRT5000 朝下，正常地面有红外反射；**桌沿（下方无反射）**和**黑胶带（吸收红外）**都让读数偏离"地面电平"。任务24 里防跌落逻辑早就写了但被 `EDGE_GUARD_ENABLE=0` 关着——今天真正启用，一套检测通吃两个需求。开机自标定：车摆普通地面静止 2s，每 50ms 采样、每侧多数表决出地面电平；两侧读数不稳定（1/0 交替）时打印 `UNSTABLE? check position!` 提示重新摆位（车压胶带上的典型症状）。触发即：停 → 倒车 300ms → 朝另一侧转 90°（远离边线）。检测带 3ms 二次确认滤瞬时噪声。

### 工程拼合（两个已验证任务的叠加）

- **决策层 ← task14**（实机标定过）：超声波 <20cm → 舵机左右扫 45° 各测 3 次取中值 → 向空侧单轮支点转 90°（1400ms）；双侧堵 → 掉头 180°；测距 30ms 超时保护
- **传输层 ← task15**（昨天实机验证）：GPIO11 软件位倒 UART @9600 发 V2 帧——**实车 STM32 昨天已重烧 9600 版，今天 STM32 完全不用动**
- 决策层三处重构：
  1. **计时全部改 `hi_get_us()` 实时时间**——软 UART 一帧 10.4ms，task14 那种"循环计数当毫秒"在发帧后全部失真（task15 踩过坑的 tick 问题同款）
  2. **转向后脱离从盲直行 2s 改受控直行 700ms**——旧版 500ms 后就被 STM32 看门狗停住，且迷宫里箱子密，盲跑必撞；新版途中每 40ms 查红外，踩线立即停倒改道
  3. **演示流程工程化**：标定 2s → `Start in 3s` 倒计时（人离场窗口）→ 巡逻 120s → `DEMO DONE` 自停

### 关键细节：500ms 失效保护 × 舵机扫描

STM32 无有效帧 500ms 自动停车。测距（≤30ms）天然安全；**舵机扫描是坑**：`servo_move` 300ms 持压 + 两侧各 3 次测距×60ms + 回中等，全程都会超 500ms——所以舵机持压期间每帧 20ms 都同步发一帧 `stm32_send_frame(0,0)` 维持心跳（原地停着发零速帧，安全）。scan 序列实测 ~3.5s，全程供帧不断。

## 追记（当天下午实机）：遇障碍物不停——主循环结构 bug，已修

实机发现"刚开机在走、但遇到箱子不停"（连第一次避障都不触发）。排查确定是 **v1 主循环结构 bug**：

### 根因（一次定位）

v1 的 `forward_for(0)` 是一个"前进直到踩到红外线或演示到时为止"的**阻塞循环**，循环体里**只查红外危险和演示时间，从不调用超声波测距**。而负责避障的 `get_distance_cm()` 被放在主循环 `forward_for` 返回**之后**：

```c
rc = forward_for(0);   // 只要不踩红外线、不到时，这里永不返回
...
dist = get_distance_cm();   // ← 永远执行不到
if (dist < OBSTACLE_CM) { ... }   // ← 避障分支成死代码
```

结果车在 `forward_for` 里一路闷头前进，除非碰到桌沿/黑胶带的红外线才停——**超声波避障整个变成死代码**，遇箱不停。这正是实测现象。

### 修复（v2，对照 task14 的事件驱动循环）

把超声波测距**并入受控前进循环**，每 `STEP_MS=40ms` 同步做一次完整传感决策：

```c
static int forward_for(...) {
    for (;;) {
        if (到时)        return EV_TIMEOUT;  // 演示时间到
        if (红外危险)     return EV_DANGER;  // 踩线/胶带
        dist = get_distance_cm();            // 前方障碍实时测距
        if (dist < OBSTACLE_CM) return EV_OBSTACLE;  // 遇箱
        car_forward();
        ...
    }
}
```

主循环按返回值分流：`EV_DANGER→escape_danger`、`EV_OBSTACLE→scan_choose_side 转向`、`EV_TIMEOUT→结束`。前进、避障、防跌落三者都实时决策，不再有死代码。

### 顺手修复

`stm32_send_frame` 里右轮限幅笔误：`if (right > 150) right = -150;` → 应为 `right = 150`（正转截成了反转）。v1 巡航 60/转向 70 未触发，但属隐患，一并修。
