# 2026-09-01 任务24：系统通信协议（双核综合）

## 今日完成

**任务24（系统通信协议）**，u+ 平台任务，阶段三收尾任务：把 hi3861 和 STM32 综合起来，**小车自己跑起来，同时左转打左转向灯、右转打右转向灯**（附加需求）。

### 协议设计（讲解版）

- 物理层：UART TTL，115200-8-N-1。Hi3861 UART2（GPIO_11=TXD / GPIO_12=RXD）↔ STM32 USART1（PA9/PA10）
- 帧格式 6 字节：`0xFC | 左轮方向(0/1) | 左轮速度(×100, 圈/s) | 右轮方向 | 右轮速度 | 0xFD`

### 两侧实现

1. **hi3861 侧** `hi3861/task14_uart_correspondence/12.0_UART_Correspondence/`：
   - 讲解版 `stm32motor_control(motorA, motorB)`：负值拆方向位、限幅 ±150、装帧 `UartWrite(UART2)`
   - 动作函数 `car_forward/backward/left/right/stop`（左转 = 左轮 50 / 右轮 150）
   - 学生任务（验证四方向）：`car_demo` 循环 **前进 2s → 左转 2s → 右转 2s → 后退 2s → 停止 2s**，串口 0 打印动作名
   - 虚拟机编译 BUILD SUCCESS，固件拷回 output/
2. **STM32 侧** `stm32/8_双核协议控制/`（从任务23 PID 工程复制）：
   - `usart.c`：中断里逐字节状态机解析帧——`USART_RX_BUF[0]!=0xFC` 不计数重新找帧头，收满 6 字节且帧尾 0xFD → 提取 CAR_buff[4]、置 `uart_rec_flag`
   - `pid.c` `System_Control`（100ms）：消费帧 → 速度 /100.0f 还原 + 方向恢复符号 → **车灯状态判定** → 编码器 + 增量式 PI（复用任务23 参数）→ Set_Pwm
   - `main.c` `led_task`（主循环 10ms 分片）：按状态渲染两条 WS2812——前进=左右常亮白（日行灯）、**左转=左侧琥珀色 400ms 闪**、**右转=右侧琥珀色 400ms 闪**、后退=倒车灯（红底白芯）、停止=全灭
   - Keil 命令行编译 **0 Error 0 Warning**（`"C:/Keil_v5/UV4/UV4.exe" -b Template.uvprojx -j0`，Code=13656）

### 设计决策

- **转向灯逻辑放 STM32 侧**：协议帧只有两轮带符号转速，从核据此推断左转/右转/直行/倒车（右轮快=左转…），主核协议保持讲解原样。以后 3861 换循迹/避障逻辑（car_left_tra 等），转向灯自动跟随，协议不用改。
- **3861 单次发帧 + STM32 锁存**：讲解 demo 每 1s 互斥锁下重发；我改为动作开始发一次、STM32 锁存持续闭环，行为等价且更干净。
- **灯带布局不确定**（README 记左右各一条，任务19 代码注释写 L前/R后）：实现里加了 `LED_LAYOUT` 宏，默认按"左右"，实车若是"前后"改宏重编译（前后模式=前后带各取左半边 1~3 / 右半边 4~6 珠闪）。

### 实机验证（当天下午）✅ 跑通

烧录顺序：3861 HiBurn → STM32 ST-Link（Keil F8）→ 拔烧录线、电池供电上电。

1. **首轮：灯按节拍循环但电机嗡嗡不转**。灯能按节拍变化 = 3861→STM32 帧链路已通（车灯状态只由收到的帧驱动）；电机满 PWM 仍不转 = 电池电压不足（轮子不转→编码器反馈 0→PID 推满占空比还带不动）。**充电后恢复**。教训：USB 只够验证灯效，跑电机必须电池供电且要先看电量。
2. **二轮：转向灯看不出是哪边，好像两边都亮**。定位：灯带实为**前后各一条**（不是 README 记的左右各一条）——按左右布局渲染时"左转"点亮的是整条前灯带（横跨车头两角），自然像两边一起闪。改法：转向时前后灯带各取**对应侧半边**（3 珠）闪琥珀；前进改前白大灯+后暗红尾灯；后退倒车灯只亮后带；闪烁半周期 350ms（≈1.4Hz 更像真车）。
3. **三轮：转向灯左右反了**。前后带安装方向与假设相反，`FRONT/REAR_STRIP_LEFT_IS_LOW` 两个宏 1→0 翻转（左半边=4~6 号灯）后正确。

最终效果：小车循环 **前进（大灯+尾灯）→ 左转（前后带左半边闪琥珀）→ 右转（右半边闪）→ 后退（倒车灯）→ 停止（全灭）**，双核协议全链路 ✅。
