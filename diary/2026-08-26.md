### 五、任务7「OpenHarmony系统驱动实验 —— GPIO驱动舵机」完成 ✅

**对应任务**：阶段一 任务7 OpenHarmony 系统驱动实验 —— **GPIO 驱动舵机**（用互斥锁做多任务联动）

- **任务目标**：在 Hi3861 上用 GPIO 输出 PWM 脉冲驱动 **SG90 舵机**，结合 RTOS **互斥锁（Mutex）** 实现同优先级多任务联动，完成舵机「左转 45° → 右转 45° → 居中」顺序控制。
- **硬件接线**：SG90 舵机信号线接 Hi3861 的 **GPIO2**（查小车原理图确认）。
- **SG90 原理**：MCU 产生 **周期 20ms** 脉冲，高电平宽度 0.5ms~2.5ms 控制角度：0.5ms=0°、1.0ms=45°、1.5ms=90°（居中）、2.0ms=135°、2.5ms=180°。
- **软件方式**：不用硬件 PWM，用 GPIO 软件模拟——`set_angle(duty)`：GPIO2 先输出 `duty` 微秒高电平，再输出 `(20000-duty)` 微秒低电平，重复 10 次完成一次指定角度动作。
- **新建工程** `hi3861/task07_sg90_mutex/`（含 `3.0_SG90_Mutex` 参考版 + `student_3.0_SG90_Mutex` 学生版）：
  - **学生版（最终跑通）**：用互斥锁实现**同优先级**三任务联动，满足 U+ 验收要求：
    - 任务1（优先级25）：串口输出 1 次「任务1开始运行」，舵机左转 45°（1.0ms）
    - 任务3（优先级25）：任务1 运行 3 秒后再运行，串口输出 2 次「任务3开始运行」，舵机右转 45°（2.0ms）
    - 任务2（优先级25）：任务3 运行后立即运行，串口输出 3 次「任务2开始运行」，舵机居中 90°（1.5ms）
  - 关键 API：`osMutexNew()` 创建互斥锁，`osMutexAcquire(mutex_id, osWaitForever)` / `osMutexRelease()` 加解锁；三任务同优先级，靠互斥锁串行化对舵机的访问，用 `osDelay()` 错开时序保证「任务1 → 任务3 → 任务2」顺序。
- **编译成功**：`python3 build.py wifiiot` → **`BUILD SUCCESS`**，`app/BUILD.gn` 指向 `student_3.0_SG90_Mutex:SG90`，产物 `Hi3861_wifiiot_app_allinone.bin` = 778856 字节（确认学生版）。
- **实机烧录成功** 🔥：HiBurn（allinone.bin）烧录并验证；串口依次输出「任务1开始运行」「任务3开始运行」「任务2开始运行」，舵机按 **左转 45° → 右转 45° → 居中** 循环动作。

**任务7 完成，可在 u+ 平台勾选。阶段一进度 4/10。**

### 六、任务21「STM32 PWM驱动电机」完成 ✅

**对应任务**：阶段三 任务21 STM32 PWM驱动电机（让小车跑起来）

- **任务目标**：在 STM32F103 上产生 PWM 信号驱动直流电机，让「QST先锋号」小车动起来。
- **硬件**：主控 STM32F103（外部晶振 8MHz × 9 倍频 = 72MHz）；电机驱动芯片 **L9110S**；方向引脚 PB13(BIN)/PB14(AIN)。
- **PWM 配置**：TIM4 通用定时器，PB6=CH1、PB7=CH2 复用推挽输出；`PWM_Init(7199, 9)` → 频率 = 72M/(9+1)/(7199+1) = **1000Hz**；占空比 = 比较值/7200。
- **新建工程** `stm32/4_PWM驱动电机/`（从 02 模板复制改造），新增电机驱动模块：
  - `USER/motor.h`：方向引脚宏（`AIN=PB14`、`BIN=PB13`）+ PWM 寄存器宏（`PWMA=TIM4->CCR1`、`PWMB=TIM4->CCR2`）
  - `USER/motor.c`：`Motor_Init()`（方向引脚初始化）、`PWM_Init(arr,psc)`（TIM4 PWM 初始化，1000Hz）、`Set_Pwm(moto1,moto2)`（**>0 前进、<0 后退**）
- **老师要求的丰富运动功能 —— 前进 2 秒 → 后退 2 秒** ✅：
  ```c
  while (1) {
      Set_Pwm(2500, 2500);       // 前进
      delay_ms(1000); delay_ms(1000);   // 前进 2 秒
      Set_Pwm(-2500, -2500);     // 后退
      delay_ms(1000); delay_ms(1000);   // 后退 2 秒
  }
  ```
- **编译成功**：Keil MDK5 编译 `0 Error(s)`（Build Output），生成 `Template.axf` / `Template.hex`（ST-Link Debugger 下载器已配好）。
- **实机运行成功** 🔥：烧录到「QST先锋号」小车后，小车**前进 2 秒 → 后退 2 秒**循环跑动，任务完成。
